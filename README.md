# Время — деньги

Визуальный эксперимент: смотрите, сколько денег зарабатывает один человек или целая группа людей, пока вы находитесь на странице.

## Запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev-сервер
npm run dev

# 3. Открыть http://localhost:5173 в браузере
```

## Production-сборка

```bash
npm run build        # TypeScript + Vite production bundle
npm run preview      # локальный просмотр собранного проекта
```

## Проверки

```bash
npm run typecheck    # проверка типов TypeScript
npm run test         # unit-тесты (41 тест)
```

## Что реализовано

- **Стартовый экран** — ввод зарплаты и количества людей с валидацией и предпросчётом.
- **Точный таймер** — `performance.now()` + `requestAnimationFrame`, без `setInterval`. Пауза/продолжение/сброс без скачков.
- **Сегменты расчёта** — смена параметров во время сессии фиксирует заработанный объём и применяет новые параметры только к будущему.
- **Анимация денег** — авторские SVG-монеты (1, 2, 5, 10 ₽) и банкноты (50–5000 ₽). Интенсивность плавно зависит от общего дохода группы. Жёсткие лимиты: ≤ 60 объектов на экране, ≤ 18 спавнов/сек.
- **Форматирование по РФ** — пробелы между тысячами, запятая для дробей, символ ₽.
- **Адаптивность** — мобильные, планшеты, десктоп.
- **`prefers-reduced-motion`** — уменьшение анимации для пользователей с соответствующей настройкой.
- **Unit-тесты** — 41 тест: расчёты, лимиты анимации, монотонность потока.

## Ограничения

- Анимация — визуальная метафора; счётчик вычисляется независимо по формуле.
- Для >1000 человек интенсивность анимации ограничена потолком (60 объектов, 18 спавнов/сек), но расчёт суммы остаётся точным.
- Данные не сохраняются между перезагрузками страницы.
- Бэкенд, авторизация и внешние API не используются.
